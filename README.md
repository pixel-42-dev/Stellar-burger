<h1>Проект Яндекса: 'Stellar Burger'</h1>

## Приложение космической бургерной предоставляет такие возможности, как:
- Сборка бургера (React Drag and Drop)
- Просмотр информации об ингредиенте
- Просмотр ленты заказов
- Регистрация, авторизация
- Редактирование данных пользователя в личном кабинете

## Стек технологий
- React
- Redux
- TypeScript

## Установка, настройка
- Клонирование репозитория: `git clone`
- Установка необходимых зависимостей: `npm install`
- Сборка стабильной версии: `npm build`
- Запуск проекта: `npm start`
- Публикация проекта на GitHub Pages: `npm run deploy`
